# MOVE FLOW

집을 팔고 새집을 사서 이사하는 과정을 한곳에서 계획하고, 검증된 외부 서비스와 연결하는 한국형 모바일 플랫폼.

> **복잡한 이사, 다음에 할 일부터 차근차근.**

## 제품 방향

MOVE FLOW는 매도와 매수를 동시에 진행하는 첫 이사 경험자를 위해 일정, 서류, 자금, 가족의 할 일을 하나의 여정으로 연결하고, 필요한 전문가와 생활 서비스를 찾고 비교하도록 돕습니다. 이사를 게임처럼 만들기보다, 다음 행동을 분명히 보여주고 한 단계씩 완료하는 가벼운 진행감을 제공합니다.

## 핵심 사용자

- 한국에서 첫 매도·매수 또는 첫 독립 이사를 준비하는 20~40대
- 배우자·연인·가족과 일정을 함께 조율하는 사람
- 부동산 거래 절차와 이사 준비를 어디서부터 해야 할지 막막한 사람

## 첫 MVP 시나리오

**기존 집 매도 + 새집 매수 동시 진행**

사용자가 거래 및 이사 날짜를 등록하면, 매도·매수·대출·서류·이사·입주 단계를 하나의 타임라인과 업무 목록으로 관리합니다. 완료된 일과 다음 마감일을 홈에서 바로 확인하고, 가족에게 업무를 나눌 수 있습니다.

## 첫 10개 화면

1. 시작 화면
2. 이사 유형 선택
3. 홈 대시보드
4. 단계별 미션
5. 통합 일정 관리
6. 서류 관리
7. 자금 관리
8. 가족 공동 관리
9. 이사 서비스 연결
10. AI 이사 도우미

## MVP 범위

- 매도·매수 통합 타임라인과 일정별 할 일, 마감 알림
- 거래 유형에 맞는 서류 체크리스트와 제출 기한 안내
- 계약금·중도금·잔금 및 이사 비용 일정 관리
- 가족 공동 일정, 담당자 지정과 완료 상태 공유
- 외부 이사·청소·법무·인테리어 업체에 견적 요청 및 비교
- 가구·가전 중고 판매·나눔·폐기, 대형 폐기물 신고·수거 방법 안내
- 사용자 일정과 등록 정보를 바탕으로 다음 일을 쉽게 설명하는 AI 가이드

## 서비스 연결 방식

MOVE FLOW가 모든 서비스를 직접 운영하기보다, 초기에는 검증된 외부 업체·공공 안내를 연결하고 견적 요청과 비교 과정을 단순하게 만듭니다. 서비스별로 지역, 일정, 포함 범위, 추가 비용, 광고·제휴 관계를 비교하기 쉽게 보여줍니다. 법무사·이사·청소·인테리어 등 공급자 검증과 제휴 범위는 시장 조사와 파트너 확인을 거쳐 구체화합니다.

## UX 원칙

- 홈 첫 화면에서 사용자가 **이사가 어디까지 진행됐는지, 오늘 할 일은 무엇인지, 다음 준비는 무엇인지** 바로 알게 합니다.
- 쉬운 한국어와 실제 생활 용어를 사용하고, 불안을 키우는 경고보다 구체적인 행동을 안내합니다.
- 보라색을 차분한 브랜드 포인트로 쓰고, 진행 표현은 체크와 단계 표시로 제한합니다.
- 비용·서류·일정은 한눈에 읽히게 하고, 상세 설명은 필요할 때 펼쳐봅니다.
- 추천 업체는 검증 기준, 광고·제휴 관계, 견적 조건을 투명하게 표시합니다.

## 투자자 설명 한 문장

**MOVE FLOW는 처음 집을 사고팔며 이사하는 사람에게 일정·서류·자금·가족 업무와 믿을 수 있는 생활 서비스를 하나의 실행 가능한 여정으로 연결하는 한국형 주거 이동 플랫폼입니다.**

## 제품 개발 단계

UX 리서치 → 한국 시장 경쟁·대체재 분석 → PRD → IA와 사용자 흐름 → 화면 디자인 → MVP 개발 → 사용자 테스트 → 포트폴리오 정리

## 첫 화면 시안

프로젝트 루트의 [`index.html`](./index.html) 또는 [`prototype.html`](./prototype.html)을 열면 홈·일정·준비·서비스·마이 화면을 둘러볼 수 있는 인터랙티브 프로토타입입니다. 일정 체크, 할 일 추가, 전문가 분야 전환을 체험할 수 있습니다. [`showcase.html`](./showcase.html)에서는 기존 10개 주요 화면 시안을 비교할 수 있습니다. 실제 업체 연결, 견적 산출, 계정·공동 편집, 일정·법률·금융 데이터 연동은 구현 전이며 화면 속 정보는 예시입니다.
